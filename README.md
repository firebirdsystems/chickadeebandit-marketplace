# Marketplace

A [Chickadee Bandit](https://chickadeebandit.com/app-library/marketplace) app.

Neighborhood buy/sell/give-away board — list items with photos, browse by category, ask the seller a question, and let leadership moderate flagged listings.

## Features

- Listings with photos and categories.
- Questions to the seller.
- Flagging and leadership moderation.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-marketplace/releases/latest/download/bundle.json
```
